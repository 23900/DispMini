# DispMini Troubleshooting

The troubleshooting guide is on the DispMini website: **[dispmini.app/troubleshooting](https://dispmini.app/troubleshooting)**

It covers connection, picture, sound, keyboard and mouse, and restart problems. Start by checking the device's status dot in the Mac mini's menu bar; the setup guide [explains the colors](https://dispmini.app/setup-guide#check-your-connection).

## Common problems

- [The Mac mini can't find the iMac](https://dispmini.app/troubleshooting#the-mac-mini-cant-find-the-imac)
- [It's connected, but there's no picture](https://dispmini.app/troubleshooting#its-connected-but-theres-no-picture)
- [The picture stutters or shows artifacts](https://dispmini.app/troubleshooting#the-picture-stutters-or-shows-artifacts)
- [There's no sound](https://dispmini.app/troubleshooting#theres-no-sound)
- [The keyboard and mouse don't control the Mac mini](https://dispmini.app/troubleshooting#the-keyboard-and-mouse-dont-control-the-mac-mini)
- [I can't exit fullscreen](https://dispmini.app/troubleshooting#i-cant-exit-fullscreen)
- [It doesn't start or reconnect after a restart](https://dispmini.app/troubleshooting#it-doesnt-start-or-reconnect-after-a-restart)

Still stuck? [Open an issue](https://github.com/23900/DispMini/issues) with [these details](https://dispmini.app/troubleshooting#still-stuck).
