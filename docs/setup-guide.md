# DispMini Setup Guide

The setup guide is on the DispMini website: **[dispmini.app/setup-guide](https://dispmini.app/setup-guide)**

It shows how to connect an iMac to an Apple silicon Mac mini or MacBook with a Thunderbolt or USB4 cable, install both apps, and allow the permissions macOS asks for. It takes a few minutes and you only do it once.
